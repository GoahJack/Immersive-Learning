# 学习陪伴软件项目文档

当前状态：**0.1.3 首版已实现并完成构建，核心逻辑与桌面流程已有自动化验证；人工系统验收与一周学习试用仍待完成。**

本目录记录 Windows 学习陪伴软件的首版需求、技术设计和验收依据。安装包、源码运行与检查命令见[项目运行说明](../README.md)，实际验证范围见[验收清单](acceptance.md)。

## 项目目标

【用户已确认】面向个人在 Windows 电脑上学习的场景，兼顾纸质课本。学习内容包括高数课本、B 站算法教程、B 站四级听力训练。需要同时应对开始前拖延、学习中分心、缺少计划的问题，并支持指定时间提醒和学习时长记录。

【用户已确认】关闭主窗口后仍需提醒；学习时悬浮界面默认收起，只在提醒时出现，可以采用灵动岛样式。

【用户已确认】每周练习的习惯任务与固定某天的日期计划是两类不同任务，分别创建和管理。

【方案默认值】首版定位为学习陪伴台，核心闭环是：

> 安排学习 → 到点提醒 → 开始专注 → 暂停或继续 → 结束并记录进度 → 下次接续。

## 需求来源标记

以下标记是所有文档的共同约定。小节中的统一标记适用于该小节内的全部条目，表格中的逐项标记优先。

| 标记 | 含义 |
| --- | --- |
| 用户已确认 | 用户在对话中明确提出或选择的需求，不表示已经实现 |
| 方案默认值 | 为形成可实施的首版方案提出的默认行为或技术判断，不等同于用户逐项确认 |
| 后续扩展 | 不纳入首版开发与验收的候选能力，不承诺实施时间 |

【方案默认值】以个人 Windows 使用、简体中文界面、无需账户和服务器、本地保存数据作为首版基线。技术选型采用 Electron、React、TypeScript；这些是已落地的实现基线，仍保留“方案默认值”以区分需求来源。

## 统一术语

| 术语 | 定义 |
| --- | --- |
| 学习任务 | 每周习惯、日期计划、自由学习的共同称呼，包含材料、目标、时长和接续进度 |
| 每周习惯 | 按选定星期和时间重复提醒的练习任务，完成一次不取消后续安排 |
| 日期计划 | 只在指定年月日及时间提醒一次的学习安排 |
| 自由学习 | 不设提醒、可手动开始的学习内容 |
| 提醒实例 | 某任务在某个计划时间应发生的一次提醒；稍后提醒不创建新的实例 |
| 学习会话 | 从一次开始到结束的学习过程；同一时刻最多一个未结束会话 |
| 专注时长 | 会话运行期间累积的时间，不包含暂停、睡眠或软件退出时间；不代表实际掌握程度 |
| 进度 | 学到哪里和下一步做什么的文字记录，与专注时长分开保存 |
| 灵动岛 | 默认隐藏、提醒时在屏幕顶部展开的独立轻量窗口 |
| 关闭主窗口 | 隐藏主窗口并保留托盘后台运行 |
| 彻底退出 | 结束应用进程，此后不能由本应用继续提醒 |

【方案默认值】以上定义为产品、技术和验收文档共享的规范术语。

## 文档维护

【方案默认值】需求变化先说明影响范围、可能受影响模块和验证方式；大幅调整功能、布局、数据或权限前，询问是否同步文档。出现实现与文档偏离时，说明偏离点、原因和影响，并由用户选择调整代码、更新文档或记录偏差原因。

【方案默认值】产品行为以产品文档为准，技术文档落实实现，验收文档对应验证；发现冲突时先修订一致再实施。只有获得实际验证证据后，才将验收状态由“尚未验证”改为通过或失败。

【后续扩展】强制应用封锁、行为监控、AI 辅导、云同步、复杂积分及内置播放器均不属于首版。
