# 沉浸学习 0.1.3

- 增加自动检查与下载正式更新，可在设置中关闭。
- 设置页显示更新状态和下载进度，支持手动检查及失败重试。
- 下载完成后可选择重启安装；安装前保存当前学习为暂停，保留计划、进度和记录。
- 学习中不会自动重启，普通退出也不会触发安装。

0.1.2 及更早版本需要手动安装一次本版，之后支持自动更新。自动更新仅用于 Windows NSIS 安装版；开发版和免安装目录禁用自动更新。更新下载需要能够访问 GitHub。

当前为未配置 Authenticode 代码签名证书的个人试用版本；下载使用 HTTPS 和安装包 SHA-512 校验。首次安装及真实升级仍需按验收文档试用。
