# 产品需求与交互规范

当前状态：**0.1.2 首版已按本文实现，已完成自动化验证的范围及尚未验证项目见验收文档；不表示所有人工验收已通过。** 标记含义和术语见[项目说明](README.md)。实现方案见[技术设计](technical-design.md)，验证方法见[验收清单](acceptance.md)。

## 1. 目标与场景

【用户已确认】用户需要学习多种知识，主要使用 Windows 电脑或纸质课本；既有开始前拖延，也有学习中打开其他内容的情况。希望制定学习计划、在特定时间收到提醒并记录沉浸学习时长。

| 场景 | 来源 | 首版支持方式 |
| --- | --- | --- |
| 高数课本 | 用户已确认 | 【方案默认值】记录书名、页码或习题、本次目标和下次进度；纸质书学习无需打开文件 |
| B 站算法教程 | 用户已确认 | 【方案默认值】附课程链接，主动开始时在系统浏览器打开，结束时记录集数或时间位置 |
| B 站四级听力训练 | 用户已确认 | 【方案默认值】附训练链接，设置重复提醒，记录练习内容及下次安排 |

【方案默认值】软件帮助安排和接续学习，不自动判定是否掌握知识，不自动识别 B 站视频内容或播放进度。

## 2. 首版范围与页面

【方案默认值】首版包含独立的每周习惯、日期计划和自由学习，以及一次性与每周重复提醒、专注计时、文字进度、每日/每周统计、托盘常驻和灵动岛提醒。所有页面使用简体中文。

| 页面 | 内容和主要操作 |
| --- | --- |
| 今天 | 显示当前会话、待开始任务、下一次安排；提供开始、暂停、继续、结束入口。正在学习的会话优先显示，其次待处理任务，再按计划时间显示后续任务 |
| 每周习惯 | 独立创建、编辑、停用和归档每周练习；只设置重复星期和当天时间，保留分类、材料、目标与时长 |
| 日期计划 | 独立创建、编辑、停用和归档某天的安排；只设置具体年月日及时间，保留分类、材料、目标与时长 |
| 自由学习 | 管理不设提醒的学习内容，支持手动开始与记录 |
| 学习记录 | 展示会话列表、结束进度和每日/每周专注时长；按学习分类查看投入 |
| 设置 | 配置提醒声音、阶段提醒、开机启动；说明关闭到托盘与彻底退出的区别，提供提醒预览 |

【方案默认值】主界面用浅色背景、深色文字、蓝色操作强调；以微软雅黑为中文字体首选、系统无衬线为后备。布局突出下一项任务，减少装饰。深色胶囊灵动岛是主要视觉特征。支持键盘操作、清晰焦点和减少动态效果的系统偏好。

## 3. 任务与接续进度

【方案默认值】任务字段及规则如下：

| 项目 | 规则 |
| --- | --- |
| 名称、分类 | 名称必填；分类可自定义，未设置时归为“未分类” |
| 材料 | 纸质课本、网页链接、本地文件、其他四选一；纸质或其他材料允许只填说明 |
| 本次目标 | 可选文字，例如“阅读第 32—36 页并做两道例题” |
| 计划时长 | 必填，默认 25 分钟，可设 1—240 分钟；默认值可在单次开始前调整 |
| 任务类别与提醒 | 每周习惯：指定星期及时间；日期计划：指定年月日时间；自由学习：不提醒。创建入口和编辑表单分开，每个任务只有所属类别的规则 |
| 接续进度 | 可选的“学到哪里”“下一步”；下次开始时展示 |

【方案默认值】安排按 Windows 当前本地时间执行，每周从周一开始。新建一次性提醒必须在未来，每周规则至少选择一个星期。完成一次学习不会自动完成或停用整个重复任务。归档替代物理删除，保留历史记录；归档会取消该任务后续未处理提醒。

## 4. 学习与灵动岛流程

【用户已确认】学习时悬浮界面默认收起，只在提醒时出现；可设计为灵动岛样式。关闭主窗口后仍能提醒。

【方案默认值】“收起”定义为完全隐藏，不保留常驻胶囊。灵动岛位于主显示器工作区顶部居中，置顶但不抢键盘焦点，宽度适应工作区；托盘仍可随时打开当前会话或主窗口。

| 步骤 | 操作与反馈 |
| --- | --- |
| 到点 | 灵动岛显示任务名、目标、时长和“开始学习”“先学 5 分钟”“稍后提醒” |
| 开始 | 建立会话；主动点击开始时打开任务所附网页或文件，纸质书无额外操作；随后隐藏灵动岛 |
| 先学 5 分钟 | 建立目标为 5 分钟的会话，不修改任务默认时长；计时结束后可继续 |
| 稍后提醒 | 同一提醒实例延后 10 分钟，不复制任务；可在“今天”中提前开始 |
| 未响应 | 灵动岛展示 15 秒后隐藏，任务保留待开始状态；不反复自动催促 |
| 暂停与继续 | 从主窗口或托盘操作；暂停期间不累积专注时长，继续后接着计时 |
| 阶段提醒 | 默认关闭；开启后，每累积 20 分钟专注时长短暂提醒回到当前任务，不自动暂停 |
| 达到目标 | 计时自动暂停，灵动岛提供“完成并记录”“继续 10 分钟”；不把无人响应时间计入专注时长 |
| 结束 | 可选填写“学到哪里”“下一步”，也可直接结束；保存会话及进度，隐藏灵动岛 |

【方案默认值】阶段提醒展示 5 秒，其余提醒展示 15 秒。所有提醒消失后都能通过托盘或主窗口处理。开始操作幂等，不因双击建立多个会话；已有未结束会话时，必须继续或结束该会话后才能开始另一个。

【方案默认值】同一时刻多个任务到点只展示一条汇总，进入“今天”选择；学习中其他任务到点仅加入待处理列表，不弹出开始提示打断当前会话。计时结束提醒优先于阶段提醒；被替代的提醒仍可从主窗口处理。

【方案默认值】温和提醒不监测当前应用、不强制锁屏或拦截网站。默认提醒声音关闭，可在设置中开启。首版采用应用内灵动岛提醒，不同时发送一份重复系统通知。

## 5. 后台与恢复规则

【方案默认值】以下是对用户后台提醒需求的具体实现约定：

| 情况 | 预期行为 |
| --- | --- |
| 关闭主窗口 | 隐藏到托盘，继续提醒、计时和保存；首次关闭说明如何重新打开与退出 |
| 从托盘彻底退出 | 若有未结束会话，确认后保存为暂停并退出；软件退出后不再提醒 |
| 开机启动 | 默认关闭，可主动开启；开启后登录 Windows 时托盘启动，不自动弹出主窗口 |
| 系统睡眠或锁屏 | 暂停当前会话；唤醒或解锁后由用户手动继续，不把离开期间算作专注 |
| 异常退出与重启 | 恢复最近成功保存的时长和未结束会话，保持暂停；不累积应用离线时间 |
| 错过提醒 | 启动或恢复时汇总尚未处理的到期提醒，不逐条补弹；每周任务仅保留最近一次错过的实例，较早实例标记已跳过 |
| 本地写入失败 | 明确提示保存失败并允许重试，不宣称数据已保存 |

【方案默认值】电脑关机、睡眠或应用彻底退出时，不能保证准时提醒；恢复后按上表补充汇总。计时依据运行期间的经过时间，不因手动修改系统时间而增加专注时长。

## 6. 统计、边界和成功标准

【方案默认值】每日统计按本地日期拆分跨午夜的专注时间，每周按周一至周日汇总；今日进行中的会话也参与统计。暂停时长单独展示，不计入专注时长；记录中区分“达到目标”和“提前结束”，两者的实际专注时长都计入统计。

【方案默认值】产品试用成功标准：能在首页直接找到下一项任务；从提醒一键开始；纸质和 B 站学习均能完整记录；下次能看到接续进度；学习中无需让主窗口或悬浮窗一直可见。经过一周试用，收集用户对启动负担、提醒干扰和接续便利性的反馈，不以累计时长推断学习效果。

【后续扩展】AI 辅导、自动读取视频进度、强制应用封锁、行为监控、云同步、多端账户、复杂积分、内置播放器与阅读器。首版不申请应用监控权限，也不承担内容理解或监督学习的职责。

## 7. 0.1.1 交互补充（历史）

【用户已确认】灵动岛胶囊外的背景透明；每项计划可选每周指定星期，或指定年月日及时间；修复阶段完成未弹出灵动岛的问题，增加动态效果。

【方案默认值】0.1.1 曾统一使用“学习时间”入口；0.1.2 已由第 8 节的独立任务入口替代。目标完成自动暂停并提醒，不受“阶段提醒”开关影响；阶段提醒开关仅控制每累积 20 分钟的轻提示。

【方案默认值】提醒展开约 420 毫秒，收起约 200 毫秒；收起结束后隐藏原生窗口。页面与对话框进入、按钮按压、专注状态和进度变化提供克制的反馈；系统开启减少动态效果时取消这些动画。默认仍完全隐藏，不增加持续占屏的装饰。

## 8. 0.1.2 每周习惯与日期计划分开

【用户已确认】每周练习的习惯任务与固定某天的计划提醒属于不同类别，需分开。同步更新本文、技术设计和验收场景。

【方案默认值】保留共同的学习会话和提醒底层，采用以下独立交互：

| 类别 | 创建和编辑 | 列表与持续行为 |
| --- | --- | --- |
| 每周习惯 | 从“每周习惯 → 新建习惯”进入；只展示星期选择及每周学习时间 | 只显示习惯，完成一次仍按周提醒 |
| 日期计划 | 从“日期计划 → 新建日期计划”进入；只展示学习日期与时间 | 只显示指定日期计划，每个计划时间仅提醒一次 |
| 自由学习 | 从“自由学习 → 新建自由学习”进入；不展示日期与星期字段 | 只显示不设提醒内容，手动开始 |

【方案默认值】“今天”统一展示学习入口，但按以上类别分组并标明类型，各组可进入对应管理页。通用“新建任务”和场景模板先选择类别，再进入相应表单；模板只预填学习内容，不生成示例记录。编辑时不提供类别互转，避免把持续练习误改成一次性安排；可归档后在另一类别新建。

【方案默认值】已有任务自动按原规则归类，每周 → 每周习惯、一次性 → 日期计划、不提醒 → 自由学习；不复制任务，不更换 ID，不清除提醒实例或学习记录。原有停用、归档、进度、单会话、托盘提醒等规则继续适用。日期计划已经提醒或学习后仍可查看与手动再学，不自动归档；再次手动开始不会增加一次性提醒。
