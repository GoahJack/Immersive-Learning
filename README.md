# 沉浸学习

面向 Windows 的个人学习陪伴软件，支持纸质课本、网页 / B 站课程和本地文件。

首版包含每周习惯、日期计划、自由学习、重复提醒、专注计时、进度记录、每日与每周统计、系统托盘以及默认隐藏的灵动岛提醒。数据保留在本机，无需账户。

## 使用

正式安装包可从 [GitHub Releases](https://github.com/GoahJack/Immersive-Learning/releases/latest) 下载。本机构建安装包位于 `release/StudyCompanion-0.1.3-Setup.exe`；解压版目录为 `release/win-unpacked/`，其中 `沉浸学习.exe` 可以直接启动，须保留整个目录。打包产物不纳入版本控制。

1. 在“每周习惯”创建固定星期练习，在“日期计划”创建某天的一次性安排；不设提醒的内容放在“自由学习”。填写材料、目标和时长。
2. 到点从灵动岛开始，或从“今天”手动开始；可以先学 5 分钟。
3. 关闭主窗口后继续在托盘运行。双击托盘图标打开，右键可以暂停、继续、记录或退出。
4. 结束时留下进度与下一步，下次接着学。

电脑睡眠、锁屏后会暂停计时，需要手动继续。关机、睡眠或彻底退出时无法准时提醒，回来后汇总待处理任务。开机启动默认关闭，仅安装版本支持开启。

## 开发与检查

使用 Node.js 24 LTS 和 npm，在项目根目录执行：

```powershell
npm ci
npm exec -- install-electron --no
npm run dev
```

开发模式支持前端热更新；修改主进程、preload 或核心逻辑后需要退出并重新执行 `npm run dev`。

```powershell
npm test                 # 核心计时、提醒和保存测试
npm run build            # 类型检查与生产构建
npm run test:desktop     # 真实 Electron 桌面自动化，需要可用的 Windows 桌面
npm start                # 启动已构建应用
npm run dist             # 生成 Windows x64 NSIS 安装包
npm run test:packaged     # 对打包后的应用执行桌面测试，需先打包
npm run test:updates      # 真实更新下载、错误校验和重试，需先打包
```

首次下载依赖、Electron 运行时和打包组件需要网络；日常纸质学习、计时和查看记录无需网络。打开在线课程需要网络。

应用图标已包含在项目中，需要重新生成时执行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/create-icon.ps1`。

## 0.1.3 更新

Windows 安装版启动 30 秒后检查更新，此后每 6 小时检查；发现正式新版时后台下载。可在“设置 → 软件更新”关闭自动检查、手动检查或重试。下载好后点击“重启并更新”，确认后保存学习为暂停再安装；普通退出和学习中都不会自动安装。

0.1.2 及更早版本需手动安装一次 0.1.3，此后才具备更新能力。免安装目录、开发版、测试版禁用更新；检查和下载依赖 GitHub 连通性。发布流程见[自动更新与发布](docs/updates.md)。

## 0.1.2 更新（历史）

- 每周习惯与日期计划使用独立导航、创建入口、表单和列表，首页按类别分组。
- 每周习惯只设置星期和时间；日期计划只设置年月日及时间。编辑时不切换任务类别。
- 原有每周、一次性、不提醒任务自动对应到每周习惯、日期计划、自由学习；保留 ID、进度和历史记录。

## 0.1.1 更新（历史）

- 灵动岛根页面和原生窗口同时透明，只保留胶囊本体。
- 当时每项计划统一提供“学习时间”选项；0.1.2 已改为独立任务入口。
- 提醒加入独立事件标识、显示就绪与可见性校验；关闭提醒窗口不会销毁窗口。目标完成提醒始终启用，每 20 分钟的阶段提醒仍为可选项。
- 增加展开/收起、页面切换、对话框、按钮和进度动效，尊重系统减少动态效果设置。
